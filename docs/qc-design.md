# EEG / SEEG / ECoG QC 设计

本文描述目标产品；实现状态以 [overallplan](../overallplan.md) 为准。当前已具备读入基础和演示图，尚无完整人工工作台。

## 三种模态各查什么

| 模态 | 技术检查与证据 | 人工复核重点 | 不做的推断 |
| --- | --- | --- | --- |
| 共用 | 文件完整性；增益/偏置/单位；采样率和分段；类型/重复名/参考声明；平线、断续、饱和、工频、宽带噪声、瞬态、漂移；有效时长 | 同窗原始波形、PSD、局部和整段指标；确认是全道问题还是某段问题；参考/辅助通道不得混入神经通道阈值池 | 没有数据不能写“正常”；无硬件量程不能把所有极值称饱和；无同步参考不能写“无 ECG/EMG 伪迹” |
| EEG | 额区眼动候选；同步 ECG 的锁时/相关证据；EMG 参考与高频能量；参考污染和疑似桥接 | 看原始与显示滤波的区别；对齐 ECG/EOG/EMG 参考；区分睡眠波、运动、节律、癫痫尖波与技术异常；决定坏道/坏段 | 无电极位置不做空间邻接判断、头皮插值或源定位；高相关不等于桥接已确认；不做 ICA |
| SEEG | 平线、松动/跳变、工频、局部与共模噪声；参考通道问题；已存储双极信号的身份和来源 | 同时看明确指定通道组；查看问题是否随参考传播；保护 IED、发作和 HFO；显式确认原通道到双极配对的映射 | 名称相邻不自动判同杆/相邻触点；不把高频、尖峰或幅度离群自动删掉；不重复做未知双极变换 |
| ECoG | 坏道、突跳、工频、短时肌电样高频；共模/参考污染；事件与采样时间关系 | 只按名称列表和用户确认的组导航；跨通道同窗看共模；任务高频需结合事件保留；独立事件文件时钟要确认 | 无位置不建网格邻接、不做空间插值/网络适配；相同文件起始秒不能证明采样点对齐 |

所有自动项只输出 `candidate + evidence + configuration + input fingerprint`，不能直接形成删除清单。检测用保真样本；显示降采样和概览不进入指标计算。ECG 耦合可能来自共同神经/运动因素，EMG 频带也包含真实神经活动，均需人工判断。

## 人工复核与界面

单页工作台以 recording 为单位：左侧通道和候选队列；中央原始波形、可切换 PSD/辅助参考；右侧证据与决定；底部显示真实分段、缺口和当前窗口。没有 CT/MRI/3D 或坐标入口。

1. 导入后先核对 modality、通道类型、单位、原始参考、采样率与分段。未知字段可继续查看，但涉及该字段的计算显示“不可计算/待确认”，不能自动补猜。
2. 点击候选定位到精确样本窗口；保留上下文。框选可新增坏段，拖动两端调整；通道标签可切换全道/选段范围。原始数据始终可见。
3. 每个候选有“确认、否决、待定”；人工新增有原因选项和可选备注。批量操作先显示影响的通道、时长和派生配对；支持撤销。
4. 显示滤波开关只改变视图，并显示参数。应用到数据必须另建明确的派生版本。换参考必须显示参与通道、排除通道和配对；不从名称自动生成连接关系。
5. “保存草稿”不发布。提交前显示仍待定数量、保留时长、排除通道和同窗前后对照；冲突时基于 revision 提示重载/合并，不能后写覆盖先写。
6. 发布后不可改写原决定，后续修订产生新版本。切换版本可以复现对应原始窗口、指标和决定。切换记录的异步响应必须核对 recording 身份后再绘制。

首版支持的人工决定是通道级和通道×时间区间级掩码，保留 sample-index 半开区间。审核不等于必须清洗；允许“保留但标注”，让下游明确选择。

## 下游拿什么

计划的发布包包含：

| 文件/对象 | 必须携带 |
| --- | --- |
| manifest | schema/software/config 版本；recording、raw artifact、hash；QC revision；审核者/时间；状态与限制 |
| channel table | 稳定 channel_id、原始名称/索引、类型、原单位/换算、参考、最终可用状态与原因 |
| interval table | stream/segment/clock、原始样本半开区间、适用通道、确认/否决/待定来源、理由 |
| decisions/audit | 自动候选和人工决定分开；新增、撤销、提交的版本链；并发基版本 |
| optional derived | 原始父 ID/hash、明确处理参数/顺序、输出单位、保留样本和通道映射；不能只有一个脱离来源的数组 |
| report | 同窗原始/候选/审核后图；覆盖和局限；不能拿显示滤波图代替科学处理说明 |

消费者必须显式选择 revision，验证 hash、单位、通道与时间映射，记录实际使用的版本。尚未审核的包只能以 `unreviewed` 明确接收，不能伪装成已通过；某项未知只限制依赖它的操作。物理单位、原始身份或时间映射错误时阻止依赖该数据的计算，消息要说明如何修复。

默认交付掩码和决定；不把坏段填零、不静默拼时间、不覆盖 raw。必要时输出保留片段列表，保留片段到原始时钟的映射。

## 三阶段验收图

- 原始：真实校准信号、单位、时间、通道顺序。
- 人工审核前：同窗叠加自动候选和证据；不能改变比例制造改善。
- 人工审核后：同窗显示人工决定、保留/排除掩码和剩余问题。没有真实人工决定就显示“待审核”。

真实无标注案例只能证明流程和可观察证据；检测准确率需独立专家标签。合成信号可以验证已知注入是否被发现，模拟审核只验证决定传播，不证明临床有效性。
