# EEG QC 设计

**每个 EEG 输入文件产出一份主报告，供人按指标、波形和频谱完成 QC。** 流程为：读取 → 自动测量与初评 → 人工复核 → 最终评价。函数与 Linxi 接口见 [模块与接入](portability.md)，公式与参数见 [方法说明](eeg-methods.md)。

## 一份文件，一份报告

主报告绑定输入文件指纹，写清文件标签、通道、采样率、采集参考和本次分析范围。每次重新分析保存新的运行版本。

| 输入情况 | 报告组织 | 人工复核 |
| --- | --- | --- |
| 单个连续段 | 一份质量总结，随后展开证据图 | 核对分析范围和关键通道 |
| 同文件多个分析段 | 一份文件报告，先列分段摘要，再进入各段证据 | 逐段确认问题，最后填写文件结论 |
| 重叠片段 | 标明主分析段和补充观察段，覆盖时长取区间并集 | 对照同一原始时刻的证据 |
| 多个输入文件 | 每文件一份主报告，批次首页只列摘要与链接 | 分别完成复核 |

**示例：** HMC 的 0–300 s、100–200 s、9000–9300 s 属于同一个文件，实际覆盖 600 s；100–200 s 是补充观察段。各段保留各自评分与可评项目，文件总分在统一分段汇总实现后计算。

## 主报告顺序

| 位置 | 内容 | 人工复核 |
| --- | --- | --- |
| 文件摘要 | 通道数、采样率、分析范围、辅助导联、自动初评与评分覆盖 | 核对采集信息、记录状态和分析用途 |
| 质量总结 | 检查项、核心指标、自动分数、主要结果；右侧单列人工复核 | 按行确认或记录调整理由 |
| 主要扣分项 | 影响最大的通道、时间、指标与分项扣分 | 优先查看对应原始片段 |
| 原始波形 | 带通道、时间、单位的 EEG，必要时加入辅助导联 | 检查异常形态与上下文 |
| 频谱与坏道 | 全通道 PSD、关键通道 α、坏道及短平线证据 | 对照同参考组、持续异常与局部坏段 |
| 工频与生理伪迹 | 50/60 Hz、ECG/EOG 锁时、EEG/EMG 同步证据 | 核对检出、重复性和影响范围 |
| 最终评价 | 分析用途、人工复评分、保留/排除范围、结论、审核人与日期 | 填写本文件最终使用意见 |

详细分项、扣分标准与人工调整栏放在 `score_report.md`，可填写表为 `score_review.tsv`。每张证据图链接对应评分表。

## 当前自动检查

| 检查项 | 输出证据 | 人工复核 |
| --- | --- | --- |
| 头文件与数值完整性 | 格式、通道表、采样率、单位标定、长度与时间轴；缺失样本范围 | 对照采集和导出信息 |
| 坏道 | PREP 稳健幅度、高频噪声、低相关；异常道数和原始区间 | 结合原始波形、同组通道与 PSD |
| 短平线与平台 | 近零恒值、文件标定端点平台及其他恒值；起止样本与上下文 | 确认停止变化及恢复的位置 |
| 工频 | 50/60 Hz、可测谐波、F 检验、峰频、振幅、受影响通道与窗口 | 核对实际频率、强度和持续范围 |
| PSD / α | Welch PSD、背景拟合、α 峰、α 功率和占比、逐窗变化 | 结合睁闭眼、睡眠或任务状态 |
| ECG / EOG | 辅助导联事件、EEG 锁时波形、重复性和影响事件窗 | 先核对事件检出，再看 EEG 同步影响 |
| 肌电相关高频 | 宽带高频、同步 EMG 包络、候选范围和有效带宽 | 对照 EEG、EMG 与平台邻近片段 |

**示例：** T8 的高频异常累计 56 s，列为持续异常候选；F8 仅在 56–57 s 低相关，列为局部异常。审核者分别填写通道意见和局部时间范围。

## 评分与人工评价

自动初评按本次可评项目的固定权重折算为整数百分制，同时列出评分版本、已评权重和未评分原因。当前权重为：坏道、工频各 20；头文件、连续性、ECG、EOG、EMG 各 10；PSD 与数值完整性各 5。具体分档以结果中的 `scoring_policy` 为准，历史报告保留原评分版本。

异常比例显示分子、分母和原始范围。时间占比按重叠区间并集计算；工频还记录受影响的通道×时间。α 峰与功率用于说明记录状态，PSD 分项评价目标频带的可分析性。

人工评分调整记录“分项得分＋理由”；数据使用决定记录“通道＋原始样本区间＋保留/排除”。最终结论可填：可用、局部处理后可用、重点处理后复核、可用性受限。

## 输出与实现状态

| 输出 | 内容 |
| --- | --- |
| `review_report.md`、PNG | 主报告、质量总结、证据图和最终评价填写栏 |
| `quality_score.json`、`score_*.tsv` | 自动分项、评分政策、证据和人工填写表 |

单段自动检测、报告、填写表和 Linxi 自动任务入口已实现。批量文件调度、同文件多段自动汇总、人工表回读、复评分保存与审核版本提交，按 [实施计划](../overallplan.md) 接入。
